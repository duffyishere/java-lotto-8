# java-lotto-precourse

가진 금액에 맞춰 로또를 구매하고 당첨 번호와 비교하여 당첨 내역 및 수익률을 출력해주는 프로그램입니다.

## 주요 기능

### 1. 로또 구입 금액 입력

- `구입금액을 입력해 주세요.`를 출력한다.
- 로또 구입금액을 입력받는다.
- 입력값이 숫자가 아닌 경우 `IllegalArgumentException`을 발생시킨다.
- 입력값이 1000원으로 나누어 떨어지지 않는 경우 `IllegalArgumentException`을 발생시킨다.

### 2. 당첨 번호 입력

- `당첨 번호를 입력해 주세요.`를 출력한다.
- 당첨 번호를 입력받는다.
- 번호는 쉼표(,)를 기준으로 구분한다.
- 각 번호가 1~45 사이의 정수가 아닌 경우 `IllegalArgumentException`을 발생시킨다.
- 입력된 번호가 6개가 아닌 경우 `IllegalArgumentException`을 발생시킨다.
- 중복된 번호가 존재할 경우 `IllegalArgumentException`을 발생시킨다.

### 3. 보너스 번호 입력

- `보너스 번호를 입력해 주세요.`를 출력한다.
- 보너스 번호를 입력받는다.
- 입력된 번호는 쉼표(,)를 기준으로 구분한다.
- 각 번호가 1~45 사이의 정수가 아닌 경우 `IllegalArgumentException`을 발생시킨다.
- 보너스 번호가 당첨 번호와 중복된다면 `IllegalArgumentException`을 발생시킨다.

### 4. 로또 번호 생성

- 로또는 1~45 범위의 중복되지 않는 정수 6개로 구성된다.
- 로또 번호는 오름차순으로 정렬된다.
- 구매한 로또 수량과 로또 번호를 출력한다.

### 5. 당첨 결과 계산

- 구매한 로또와 당첨 번호를 비교한다.
- 일치 개수와 보너스 번호 일치 여부에 따라 등수를 결정한다.

| 등수 | 기준              |             상금 |
|----|:----------------|---------------:|
| 1등 | 6개 일치           | 2,000,000,000원 |
| 2등 | 5개 일치           |    30,000,000원 |
| 3등 | 5개 일치, 보너스 불 일치 |     1,500,000원 |
| 4등 | 4개 일치           |        50,000원 |
| 5등 | 3개 일치           |         5,000원 |

### 6. 당첨 통계 출력

- `당첨 통계`와 `구분선(---)`을 출력한다.
- 등수별 당첨 개수를 출력한다.

```aiignore
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

### 7. 수일룰 출력

- 총 상금을 계산한다
- 수익률 = `(총 상금 / 구입 금액) * 100`
- 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)
